# Lovely System Teambuilder

Application target: `teambuilder.ourlovelysystem.org`

Teambuilder is a collection of orchestrated team-building experience primitives.

## Current experiences

### Yellow Lion Onboarding

Path: `/yellow/`

Primitive type: individual onboarding.

Design language:

> Show. Permit action. Produce consequence. Surface evidence.

The participant enters Yellow Lion Training Mode, operates the lion through a short sequence, experiences a conspicuous failure, and is shown the hydraulic-fluid warning that explains the failure.

The participant controls actions. The system controls sequence.
