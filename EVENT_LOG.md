## 2026-08-24 — Arrival order is not truth

Four independent Snake Mountain clients produced strongly convergent shared paintings, but clients One and Four missed some of the same strokes. The result was good enough to expose the remaining defect clearly: a late pointer batch could be discarded merely because a newer batch arrived first.

The receiver was changed to reorder samples inside the existing 45-millisecond presentation buffer. A sample is now rejected only when its sequence is older than a sample already rendered—not merely older than one already received.

Implementation record: [Pointer Batch Reordering](records/2026-08-24-pointer-batch-reordering.md)

**Result:** Published. Frontend-only. Retest pending. Arrival order is no longer accepted as sequence truth.
